# Booknest

## Installation

Requires Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local URL shown in the terminal.

## API used

Booknest uses the [Open Library Search API](https://openlibrary.org/dev/docs/api/search) to find books and display their title, author, publication year, and cover.
